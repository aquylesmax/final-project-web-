# Conecta+

Projeto web para descobrir eventos, conhecer experiências locais e organizar uma agenda pessoal.

## Tecnologias
- HTML
- CSS
- JavaScript
- LocalStorage para persistência local da agenda

## Executar
Abra o projeto no VS Code ou GitHub Codespaces e inicie um servidor estático, por exemplo com a extensão Live Server.

## Observação
Os eventos atuais são dados demonstrativos e não representam confirmações de eventos reais.
